# ד״ר סאמר בשארה

פרופיל FindMed לרופא שיניים בטירה. הפרטים התקבלו ב־11 באוגוסט 2026.

## פרטים שנמסרו

- יותר מ־12 שנות ניסיון ברפואת שיניים.
- תחומי טיפול: יישור שיניים, שתלים דנטליים, שיקום הפה, רפואת שיניים אסתטית, כירורגיה דנטלית וטיפולים כירורגיים מורכבים.
- כתובת: סמארה סנטר, קומה א׳ מעל בנק לאומי, הרחוב הראשי, טירה.
- טלפונים: 052-266-3003, 050-224-4148.
- שעות פעילות: שני, רביעי, חמישי ושבת, 10:00–20:00.
- לימודים והכשרה: תואר D.M.D. והשתלמויות ברפואת שיניים משקמת ואסתטית.
- שפות: ערבית, עברית ואנגלית.
- נגישות: כניסה נגישה וחניה בקרבת המרפאה.
- ניווט: https://maps.app.goo.gl/CVzgR4RxcyaEpmvZ6
- תמונת הפרופיל נחתכה והותאמה לתצוגה באתר ללא שינוי מכוון בזהות או במראה.

## כללי הצגה

יישור שיניים וכירורגיה דנטלית מופיעים כשירותים ותחומי עיסוק. הם אינם מוצגים כתואר מומחה רשמי, משום שלא נמסרה תעודת מומחה מוכרת.

## פרטים שטרם נמסרו

- מוסד הלימודים.
- תעודות מומחה או הכשרות רשמיות.
- הסדרים וביטוחים.
- דוא״ל, אתר או עמוד עסקי.
